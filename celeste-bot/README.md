# Céleste — бот приёма заказов

Менеджер жмёт /order → выбирает категорию → позицию → количество →
пишет примечание → красиво оформленная карточка заказа улетает в группу.

Никакой базы данных не используется: пока идёт выбор — состояние живёт
в кнопках, а примечание бот распознаёт через reply на своё же сообщение.
Поэтому это отлично работает на Vercel (serverless).

## 1. Создать бота

1. Открой @BotFather в Telegram
2. `/newbot` → введи имя и username (должен заканчиваться на `bot`)
3. Скопируй токен — он понадобится ниже

## 2. Узнать ID группы

1. Добавь бота в рабочую группу
2. Добавь туда же @RawDataBot (временно) — он покажет `chat_id` группы
   (число со знаком минус, например `-1001234567890`)
3. Удали @RawDataBot из группы, оставь только своего бота

## 3. Задеплоить на Vercel

Проще всего — через Vercel Dashboard:

1. Загрузи эту папку как новый проект (Import → загрузить как есть,
   либо через GitHub, если удобнее)
2. В настройках проекта → **Environment Variables** добавь:
   - `BOT_TOKEN` — токен из BotFather
   - `GROUP_CHAT_ID` — id группы из шага 2
3. Deploy

После деплоя у тебя будет адрес вида
`https://celeste-order-bot.vercel.app`

## 4. Подключить webhook

Выполни один раз в браузере или через curl (подставь свои значения):

```
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<твой-домен>.vercel.app/api/webhook
```

Если всё ок — придёт `{"ok":true,"result":true,...}`.

## 5. Проверка

В личке с ботом (или в группе, если разрешил) напиши `/order` —
должно появиться меню категорий.

## Как поменять цены / добавить позицию

Открой `menu.js` — там простой список категорий и позиций.
Добавляешь строку — позиция появляется в боте, деплоить заново не нужно
менять код нигде больше.

## Ограничение Vercel Hobby-плана

На бесплатном тарифе serverless-функция должна ответить в течение
10 секунд — для этого бота это с большим запасом, никаких проблем.
